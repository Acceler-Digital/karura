# KARURA — AI駆動開発 総合ソリューション

このサイトは、AI(Claude）を中核に据えた AI 駆動開発(AIDD）を、ビジネス要求からリリース・保守運用まで一貫した成果物体系として進めるための総合ソリューション **KARURA** のドキュメントです。

本リポジトリには、成果物を生成・更新するための仕組み一式(スキル定義・テンプレート・共通規約・成果物フロー・セキュリティスキャン）を収録しています。成果物そのもの(実プロジェクトの中身）は含みません。

## 収録している内容

| 構成要素 | 置き場所 | 役割 |
|---|---|---|
| スキル定義 | `.claude/skills/` | Claude が各成果物を生成・更新するための振る舞いルール |
| テンプレート | 各スキル同梱の `template.md` | 成果物の骨組み(章構成・書き方ヒント） |
| プロジェクト共通の慣習 | `CLAUDE.md` | プレースホルダ・要確認マーカー・ID 表記・文体などの横断規約 |
| 成果物フロー | [成果物フロー](./artifact-flow.md) | フェーズ間の依存・生成順 |
| セキュリティスキャン | `scripts/` + git フック | OSS 公開時のシークレット混入防止 |

## フェーズ構成

KARURA は AIDD フロー(D0 → D1 → D2 → …）に沿ってスキルを収録しています。各フェーズの成果物と生成順は [成果物フロー](./artifact-flow.md) を参照してください。

| フェーズ | 収録スキル |
|---|---|
| **D0** プロジェクト管理 | (本インデックス・成果物フロー 等のメタ情報） |
| **D1** ビジネス要求 | ビジネス要件定義書 / アクター一覧 / ドメイン定義書 / プロダクト要求仕様書 / ドメイン共通要求仕様書 / ドメイン要求仕様書 / ユーザーストーリー一覧 / ユースケース一覧 / 画面コンセプト集 |
| **D2** システム要件 | 機能一覧 / 外部システム一覧 / C4モデル レベル1(システムコンテキスト） |

## 成果物サンプルを見たい場合

KARURA を使って実プロジェクトを進めた場合に、どのような成果物体系が生まれるのかは、別途サンプルリポジトリに収録しています。埋まった状態の成果物(ビジネス要件定義書・ドメイン定義書・ユースケース一覧 等）を確認したい場合はこちらを参照してください。
