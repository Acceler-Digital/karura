# D2: 画面遷移図

## 遵守すべき重要ルール

1. **画面一覧に無い画面を描かない**: 図に置く画面は画面一覧の `SCR-*` だけとし、画面名は画面一覧と一致させる。遷移に必要な画面が画面一覧に無ければ、画面を足さずユーザーに報告する。
2. **業務の進め方を作らない**: 業務状態を進める・戻す遷移は、ドメイン要求仕様書の §業務状態遷移 と §業務運用(イレギュラー対応)にあるものだけを描く。

## 処理

### 1. 分岐する

- もし画面一覧が存在しないなら、先に作成が必要な旨を伝えて終了する。
- そうでなく、`docs/D2.system-requirements/screen-flow-diagrams/` が存在しないなら、§2(新規作成)に進む。
- それ以外なら、§3(更新)に進む。

### 2. 新規作成

#### 2.1 図を分ける

PRD §システム利用ユーザーと体験設計 の表の行ごとに 1 図とする。表に無いアクターが画面一覧の利用アクターに現れるなら、そのアクターごとに 1 図とする。ただし、利用する画面がすべて他の 1 つの図に含まれるアクターは、その図にまとめる。

1 図を 1 ファイルとし、ファイル名は図のアクターの ID とアクター名をアンダースコアでつないだもの(例: `ACT-15_ACT-16_コンプライアンス部・内部監査部.md`)とする。アクターが複数なら、ID どうしはアンダースコア、アクター名どうしは中黒で連結する。

各図には、画面一覧で利用アクターに当該図のアクターを含む画面をすべて置く。複数の図のアクターが使う画面は、それぞれの図に置く。

#### 2.2 遷移を出す

同じ利用者が続けて操作する画面の間にだけ線を引く。

- **進む遷移**: 画面一覧の並び順と画面種別(入力から確認、確認から完了 等)を、§業務状態遷移 の進む遷移に照らして引く。工程をまたいで同じ利用者が続けて操作するなら、工程間でも線を引く。
- **戻る遷移**: §業務状態遷移 の戻る遷移(修正・見直し 等)だけを引く。単に前の画面へ戻る・キャンセルするだけの遷移は引かない。
- **一覧から開く遷移**: 一覧・ダッシュボードの画面から、そこで選んだ案件を扱う画面へ線を引く。
- **例外時の遷移**: §業務運用(イレギュラー対応)の事象のうち、利用者に次の行動を示す必要があるものは、§UI/UX 方針 の例外時の体験に従って案内の画面への線を引く。入力エラーの表示のように、その画面の中で完結するものは引かない。
- **入口**: 認証の画面から、利用者が最初に使う画面へ線を引く。

もし図の中の多くの画面から同じ画面へ遷移するなら、個々の画面から線を引かず、遷移元の `subgraph` から 1 本で引く。

もし通知から起動する、別の利用者から端末を引き渡される、別の利用者の作業へ引き継ぐといった図の外との出入りがあるなら、出入口のノードを置いて線を引く。PRD §利用形態 で他の利用者の端末を介して使う利用者がいるなら、端末を引き渡す箇所を双方の図に出入口として描く。

#### 2.3 図を埋める

- 図は左から右へ流れるよう `flowchart LR` で描き、画面は画面一覧の画面分類ごとに `subgraph` で囲む。
- 画面のノード ID は `SCR<連番>` とし、ラベルは画面名と `SCR-*` を改行して並べる。出入口のノードは角丸にする。
- 線のラベルには、遷移の契機を業務上の操作・結果で短く書く。ボタン名・画面項目は書かない。一覧から開く遷移のように契機が自明な線にはラベルを付けない。
- フェーズ2 以降でだけ成立する遷移は、線のラベルに `[フェーズ2]` を付ける。
- 上流に根拠の無い遷移を引いたなら、図の直後のブロック要確認マーカーにまとめる。
- タイトルは図のアクターを `アクター名: ACT-N` の形で書く。
- `sidebars.ts` の画面一覧の直後に「画面遷移図」カテゴリを置き、各ファイルをタイトルと同じラベルで登録する。PRD の表の順に並べ、表に無いアクターの図は画面一覧で最初に現れる順に後ろへ並べる。

### 3. 更新

- 画面一覧で追加・削除・改名・利用アクターの変更があった画面と、ドメイン要求仕様書で変わった業務状態遷移・イレギュラーに関わるノードと線だけを §2 の手順で見直す。
- 削除された画面はノードと線を消し、前後の画面の線を §2.2 で引き直す。
- もし利用アクターの変更で図の分け方が変わるなら、§2.1 に従ってファイルを追加・削除し、サイドバーも合わせる。

## 完成時のセルフチェック

- 画面一覧の全 `SCR-*` が、利用アクターを含む図のすべてに現れ、それ以外の図には現れていない
- ノードの画面名が画面一覧と一致している
- どの線にもつながっていないノードが無い
- `{{` が残っていない
